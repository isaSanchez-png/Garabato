# 🎨 Garabato

**Garabato** es una aplicación interactiva de dibujo desarrollada en SwiftUI y PencilKit para iOS e iPadOS. La aplicación desafía la creatividad de los usuarios proponiendo retos de dibujo aleatorios y entretenidos.

---

### 🚀 Características
- **Retos de Dibujo Aleatorios:** Genera ideas creativas de dibujo con solo tocar un botón (ej. *"Un gato comiendo pizza"*, *"Un dinosaurio bailando salsa"*).
- **Lienzo Fluido y Genérico:** Integración completa con herramientas de dibujo y trazos gracias a PencilKit.
- **Herramientas Útiles:** Opción para limpiar el lienzo rápidamente y reiniciar el dibujo.
- **Interfaz Intuitiva:** Diseño limpio, colorido y adaptado para iPhone e iPad.

### 🛠️ Tecnologías y Librerías
- **[SwiftUI](https://developer.apple.com/xcode/swiftui/):** Declaración de la interfaz de usuario y arquitectura reactiva.
- **[PencilKit](https://developer.apple.com/documentation/pencilkit):** Framework de Apple para captura de trazos con lápiz o dedo, selector de herramientas (`PKToolPicker`) y canvas (`PKCanvasView`).
- **UIKit Integration:** Uso de `UIViewRepresentable` para integrar `PKCanvasView` dentro del flujo de SwiftUI.

### 📱 Requisitos
- iOS 17.0+ / iPadOS 17.0+
- Xcode 15.0+
- Swift 5.9+

---

### 🚀 Features
- **Random Drawing Challenges:** Generates fun and creative drawing prompts at the tap of a button (e.g., *"A cat eating pizza"*, *"A dinosaur dancing salsa"*).
- **Fluid Canvas:** Seamless integration with drawing tools and strokes powered by PencilKit.
- **Quick Controls:** Clear canvas functionality to start fresh anytime.
- **Adaptive UI:** Clean, vibrant design built for both iPhone and iPad.

### 🛠️ Technologies & Libraries
- **[SwiftUI](https://developer.apple.com/xcode/swiftui/):** Modern declarative UI framework and reactive logic.
- **[PencilKit](https://developer.apple.com/documentation/pencilkit):** Apple's native framework for low-latency stroke capturing, tool palette (`PKToolPicker`), and drawing canvas (`PKCanvasView`).
- **UIKit Integration:** Implemented `UIViewRepresentable` to seamlessly bridge `PKCanvasView` into SwiftUI views.

### 📱 Requirements
- iOS 17.0+ / iPadOS 17.0+
- Xcode 15.0+
- Swift 5.9+
